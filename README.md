# LPC2148 Embedded C Projects

🚀 Hands-on embedded projects using LPC2148 covering real-time interfacing and peripheral control.

---

## 📌 Overview

This repository contains a collection of Embedded C programs developed for the LPC2148 microcontroller. It demonstrates various peripheral interfacing and real-time applications using Proteus simulation.

---

## 🧰 Features Covered

* GPIO (LED interfacing)
* 16x2 LCD Interfacing
* 4x4 Matrix Keypad
* 7-Segment Display
* ADC (Analog to Digital Conversion)
* UART Communication
* RTC (Real Time Clock)

---

## 📂 Project Structure

```
lpc2148/
 ├── 7_SEGMENT/
 ├── LCD/
 ├── LED/
 ├── Matrix_keypad/
 ├── PROTEUS/
```

---

## 🧮 Sample Projects

* Basic Calculator using Keypad and LCD
* Multi-digit Calculator
* Switch Press Counter on LCD
* RTC Time Display on LCD
* 7-Segment Counter (0–9, 0–99)
* LED Binary Display

## 🎥 Demo Videos

Simulation videos are available in the `PROTEUS` folder.

---

## 🛠️ Tools Used

* Keil µVision
* Proteus 8
* LPC2148 Microcontroller

---

## 🚀 How to Run

1. Open project in Keil µVision
2. Compile the code
3. Load HEX file into Proteus
4. Run simulation
